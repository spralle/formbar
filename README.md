# Formbar

Headless, schema-driven form engine for React.

## Packages

| Package | Description |
|---------|-------------|
| [`@formbar/core`](./packages/core) | Headless form state, validation, transforms, middleware |
| [`@formbar/from-schema`](./packages/from-schema) | JSON Schema & Zod ingestion with layout compilation |
| [`@formbar/react`](./packages/react) | React hooks, renderers, and a11y utilities |

## Quick Start

```bash
bun install
bun run build
bun test
```

## Development

```bash
bun run dev  # starts demo app at localhost:5174
```
